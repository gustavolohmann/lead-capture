Checklist WhatsApp → Conversas

O que fazer no Business Manager + screencast para App Review

1. Produção (já no ar)

  • App: https://api-production-cbf47.up.railway.app
  • Webhook WhatsApp: https://api-production-cbf47.up.railway.app/webhooks/meta/whatsapp
  • Webhook Lead Ads: https://api-production-cbf47.up.railway.app/webhooks/meta/leads
  • Verify token: o mesmo META_WEBHOOK_VERIFY_TOKEN do Railway

2. WABA + número (Business Manager)

  1. Meta Business Suite → Contas do WhatsApp → criar/associar WABA
  2. Adicionar e verificar número de telefone
  3. No App Meta → WhatsApp → API Setup: copiar Phone number ID e WABA ID
  4. No Lead Capture: Conexão Meta → sincronizar assets (grava phone_number_id)

3. Webhook de mensagens

  1. App Meta → WhatsApp → Configuration → Webhook
  2. Callback URL: webhook WhatsApp acima
  3. Verify token: valor do Railway
  4. Assinar o campo messages
  5. Testar envio de mensagem do celular para o número da WABA → deve aparecer em Conversas

4. Business Verification

  1. Business Settings → Security Center → Start Verification
  2. Enviar docs da empresa (CNPJ, site, etc.)
  3. Sem BV, permissões avançadas de messaging costumam travar no App Review

5. Template do 1º contato

  1. WhatsApp Manager → Message templates → Create
  2. Ex.: nome lead_followup, idioma pt_BR, categoria Utility/Marketing conforme caso
  3. Aguardar aprovação
  4. No fluxo de automação: preencher “Template WhatsApp” com esse nome

6. Roteiro do screencast (App Review)

  1. Mostrar login no Lead Capture (produção HTTPS)
  2. Conexão Meta ativa + WABA/número sincronizados
  3. Lead chega (Lead Ads ou formulário) com telefone válido
  4. Automação envia template/mensagem WhatsApp
  5. No celular, responder a mensagem
  6. Abrir Conversas e mostrar a resposta inbound na thread
